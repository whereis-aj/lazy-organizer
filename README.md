# Lazy Organizer

## What I Built

Lazy Organizer is a PowerShell automation tool that sorts files into folders automatically.

## Why

File organization is repetitive and easy to procrastinate on. I wanted a simple tool that does the work for me.

## Features

- Sorts PDF files into Documents
- Sorts Word documents into Documents
- Sorts images into Images
- Sorts text files into Notes

## Example

Before:

maths.pdf
cv.docx
holiday.jpg
notes.txt

After:

Documents/
├── maths.pdf
└── cv.docx

Images/
└── holiday.jpg

Notes/
└── notes.txt
